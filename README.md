# 梦境手记 🌙

一个为单人设计的解梦网页应用：记录梦境、与 AI 温和地探讨梦的含义、长期保存档案并发现反复出现的主题。

- **记梦**：文字 / 语音输入，情绪、清晰度、标签、个人联想、睡前背景
- **解读**：AI 先适度追问（可跳过），再生成结构化的详细报告；可多轮讨论、换角度重读、标记共鸣度
- **档案**：搜索、查看、编辑、删除；原始梦境与全部解读版本永久保存
- **回顾**：情绪分布、高频标签、记录日历、近 7 天 AI 小结
- **隐私**：所有记录只存在浏览器本地；密钥只在服务器端；可导出 / 导入 JSON 备份

## 一、本地运行（自己电脑上先跑起来）

1. 安装 Node.js 18 或更高版本。
2. 复制 `.env.example` 为 `.env`，把 `DEEPSEEK_API_KEY=` 后面填成你的 DeepSeek 密钥。
3. 在项目目录执行：

```bash
node server.js
```

4. 浏览器打开 `http://localhost:3000` 即可使用。

## 二、部署到 Vercel（推荐，免费，朋友手机直接访问）

1. 把本项目上传到 GitHub（`.env` 已在 `.gitignore` 中，不会被提交）。
2. 在 [vercel.com](https://vercel.com) 用 GitHub 登录，选择 **Import Project** 导入这个仓库。
3. 在项目的 **Settings → Environment Variables** 中添加：
   - `DEEPSEEK_API_KEY` = 你的 DeepSeek 密钥
4. 点击 Deploy。完成后会得到一个 `https://xxx.vercel.app` 链接，发给朋友即可；手机浏览器打开后还能「添加到主屏幕」，像 App 一样使用。

`api/chat.js` 会被 Vercel 自动识别为接口，前端无需任何改动。

## 三、部署到其他 Node 平台（Render / Railway / 云主机）

- 启动命令：`node server.js`
- 环境变量：`DEEPSEEK_API_KEY`（必需）、`PORT`（平台指定时使用）
- 无需安装任何依赖。

## 密钥安全

- 密钥**只**放在服务器环境变量中，前端网页代码里不包含密钥，访问者拿不到。
- 如果密钥曾经泄露（例如误发给他人、提交到公开仓库），请立刻到 DeepSeek 开放平台删除旧密钥并新建一个，然后更新环境变量即可，代码不用改。

## 费用

DeepSeek 官方按 token 计费（输入 2 元、输出 3 元 / 百万 token）。一次完整解梦约几分钱，单人正常使用每月通常只需几元。可在 DeepSeek 开放平台随时查看用量。
